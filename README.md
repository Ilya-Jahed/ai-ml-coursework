# AI and Machine Learning Coursework

Course projects where I implemented core methods from scratch instead of calling library models.

| Project | What it covers |
|---|---|
| [neural-networks-from-scratch](neural-networks-from-scratch/) | An MLP in pure NumPy, built stage by stage. Part 1: regression (song popularity prediction) with preprocessing and He initialization. Part 2: MNIST multiclass classification. Part 3: analysis of SGD vs batch gradient descent, shuffling, and L2 regularization. |
| [ml-decision-tree-implementation](ml-decision-tree-implementation/) | A decision tree library written from scratch: entropy/information gain and Gini splitting, depth and minimum-sample hyperparameters, hyperparameter search, post-pruning, and tree visualization. Applied to a cleaned EuroRail survey dataset. |
| [genetic-programming-symbolic-regression](genetic-programming-symbolic-regression/) | Symbolic regression with genetic programming: expression trees, tournament selection, depth-constrained subtree crossover, subtree mutation, MSE fitness with penalty handling, and per-generation tree visualization (Graphviz) on noisy target functions. |
| [smart-traffic-light-controller](smart-traffic-light-controller/) | Computational Intelligence project: a Mamdani fuzzy controller for a two-road intersection (queue lengths in, green time out), with its 27 parameters tuned by Particle Swarm Optimization and Ant Colony Optimization and compared against a fixed-timer baseline. |

## Notes

Each folder contains its own README or notebook with details and instructions. Python throughout.
